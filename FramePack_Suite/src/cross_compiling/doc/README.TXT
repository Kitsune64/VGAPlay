                           FRAMEPACK SUITE 1.4                                 
================================================================================
OVERVIEW
--------
FramePack Suite is a professional-grade collection of 4 core command-line tools
designed for modern-to-retro multimedia processing. The suite allows you to 
ingest high-definition modern videos and export them into a highly optimized 
custom binary stream paired with 8-bit Sound Blaster audio, specifically 
engineered for smooth, high-performance playback on legacy MS-DOS hardware.
All utilities in this suite are 100% standalone, fully cross-platform (Linux, 
Windows 32-bit, Windows 64-bit, and Windows XP environments), and distributed
under the permissive open-source MIT License.
-------------------------------------------------------------------------------
PROGRAM COMPONENT DESCRIPTIONS
-------------------------------------------------------------------------------
1. PNGExtract (`PNGExtract.c`)
- Purpose: Ingests a video file via the native FFmpeg API. It extracts 
  individual frames at a target frame rate, resizes the stream into a 
  VGA-compatible 320x200 canvas (with optional proportional aspect ratio 
  padding), and applies high-quality Floyd-Steinberg error diffusion 
  dithering to map the output into an optimized 8-bit indexed PNG stream.
- Usage:
  PNGExtract <input_file> <output_dir> <fps> <max_colors> <padding_mode (0/1)>
- Example:
  PNGExtract video.mp4 ./PNG 15 256 1
2. mpg2wav (`mpg2wav.c`)
- Purpose: Extracts and demuxes the primary audio track from any multimedia 
  source file via FFmpeg. It leverages high-fidelity hardware-level software
  resampling to downmix multi-channel audio into Mono, applies anti-aliasing
  filters to downsample the frequency to a strict 11025 Hz rate, and 
  quantizes the depth to 8-bit Unsigned PCM. The output is a clean Microsoft
  RIFF WAV structure with zero bloated metadata, ensuring flawless 
  compatibility with retro Sound Blaster 1.0/2.0/Pro/16 DAC hardware under 
  native MS-DOS.
- Usage:
  mpg2wav <input_file> <PREFIX>
- Example:
  mpg2wav video.mp4 video
3. FramePack (`FramePack.c`)
- Purpose: Implements the heavy-duty production pipeline encoder. It scans 
  a directory of ordered 8-bit indexed PNG frames generated by PNGExtract, 
  performs automated color quantization, maps them to a uniform DOS 
  palette packet, compresses the indexed pixel data buffers via dependent 
  streaming LZ4 compression, and bundles the assets into a high-performance, 
  single-file custom binary video package (`.BIN`).
- Usage:
  FramePack <DIRECTORY> <PREFIX> <FPS> <MAX_COLORS>
- Example:
  FramePack ./PNG video 15 256
4. Verificator (`verificator.c`)
- Purpose: Validates the byte-level structural integrity of custom `.BIN` 
  packages created by FramePack. It parses the global file headers, reads 
  and maps the continuous index table array, sequentially decompresses the 
  LZ4 frames using continuous stream decoding, computes exact compression 
  efficiency statistics, and allows developers to extract and export any 
  specific frame back into a standard PNG image for visual analysis.
- Usage:
  Mode 1 (Analysis) : Verificator <video.bin>
  Mode 2 (Extract)  : Verificator <video.bin> <frame_index> <output.png>
- Example:
  Verificator video.bin 150 extracted_frame.png
-------------------------------------------------------------------------------
AUTOMATION SCRIPT DESCRIPTIONS
-------------------------------------------------------------------------------
1. Linux Pipeline Script (`convert.sh`)
- Purpose: Provides a fully automated interactive shell workflow for Linux 
  environments. It verifies that all compiled suite binaries exist, prompts 
  the user for the source video, output prefix, target FPS, maximum colors, 
  and padding mode, and sequentially executes PNGExtract, mpg2wav, FramePack, 
  and Verificator to generate a complete deployment-ready asset package.
2. Windows Automation Script (`convert.bat`)
- Purpose: Designed specifically for Windows command-line environments (fully 
  compatible with modern Windows and legacy Windows XP consoles). It restricts 
  the console layout to an 80x25 retro grid, guides the user through an 
  interactive setup wizard to capture conversion parameters, checks for 
  required binaries and runtime dependencies, and executes the complete 
  extraction, conversion, packing, and validation pipeline.
-------------------------------------------------------------------------------
PIPELINE WORKFLOW RECOMMENDATION
-------------------------------------------------------------------------------
To process a video for your retro MS-DOS player, follow this sequence:
1. Run PNGExtract on your source video to generate dithered 320x200 PNG frames.
2. Run mpg2wav on the same video to extract the Sound Blaster compatible WAV.
3. Run FramePack on the PNG folder to compile your custom 'video.bin' asset.
4. (Optional) Run Verificator on 'video.bin' to confirm block validities.
